# Post-Launch Roadmap

## P1: first operating cycle

- Add closing-record quality fields, validation, deduplication, and audit events.
- Ship a lean Hot Zones ranked list from internal closed-deal data: ZIP/city, closings, assignment-fee totals, averages, and recency. Add a map only if it improves decisions.
- Add persistent provider usage aggregation, budget alerts, cache-hit reporting, and operator dashboards.
- Add structured support/request codes across server endpoints.
- Expand accessibility and responsive regression coverage.

## P2: measured expansion

- Team-role administration and workspace invitation hardening.
- Advanced matching calibration, reason weighting, and outcome feedback.
- Closing cohort/trend reports and scoped exports.
- Repository cleanup of tracked backup artifacts after confirming no build dependency.

## P3: validated bets

- Geographic map layers, external heat-map data, and richer market intelligence.
- Additional blast providers and automation.
- Enterprise integrations.

Each item needs a customer problem, success metric, cost ceiling, privacy review, rollout flag, and rollback plan before implementation.
